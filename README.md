# اسکای‌روم PWA — دسترسی سریع به کلاس‌های آنلاین روی اندروید

یک **Progressive Web App** کامل و حرفه‌ای برای دسترسی سریع به کلاس‌های آنلاین [skyroom.online](https://skyroom.online) روی گوشی‌های اندروید. این PWA روی صفحه اصلی گوشی نصب می‌شود و مثل یک اپ native عمل می‌کند.

## ✨ امکانات

- 📱 **نصب روی اندروید** — از طریق Chrome به صفحه اصلی اضافه می‌شود، آیکون، اسپلش اسکرین و حالت fullscreen دارد.
- 🎨 **طراحی RTL و فارسی** — رابط کاربری کاملاً فارسی و راست‌چین با پشتیبانی از دارک مود.
- 🏠 **داشبورد کلاس‌ها** — لیست کلاس‌های ذخیره‌شده با جستجو، آمار، ویرایش و حذف.
- 🔐 **ذخیره امن اطلاعات ورود** — نام کاربری و رمز عبور فقط روی دستگاه شما (IndexedDB) ذخیره می‌شود.
- 🎤 **میکروفون و دوربین** — تست سلامت میکروفون گوشی + راهنمای فعال‌سازی مجوز.
- 🖥️ **تشخیص دقیق اشتراک صفحه** — وضعیت واقعی دستگاه را بررسی می‌کند و به‌جای دکمه‌ای که کار نمی‌کند، راه‌حل واقعی را نشان می‌دهد.
- 🔆 **Wake Lock** — صفحه گوشی در طول کلاس خاموش نمی‌شود.
- 📤 **اشتراک‌گذاری لینک** — با Web Share API لینک کلاس را به اشتراک بگذارید.
- 🔔 **نوتیفیکیشن** — اعلان شروع کلاس‌ها (با Push API).
- ⚡ **آفلاین** — Service Worker برای بارگذاری سریع اپ حتی بدون اینترنت.
- 🔍 **PWA استاندارد** — استفاده از Manifest, Service Worker, IndexedDB, Permissions API.

## 📲 اپ اندروید «اسکای‌روم پرزنتر» — اشتراک صفحه و میکروفون روی گوشی

مرورگرهای اندروید (Chrome، Samsung Internet، Firefox) متد `getDisplayMedia()` را
ندارند، پس **از داخل مرورگر** اشتراک صفحه گوشی ممکن نیست
([crbug.com/40226126](https://issues.chromium.org/issues/40226126)). برای همین این
مخزن یک اپ اندروید هم دارد (پوشه `android/`) که این کمبود را جبران می‌کند:

| قابلیت | مرورگر اندروید | اپ اندروید |
|---------|----------------|------------|
| شرکت در کلاس | ✅ | ✅ |
| میکروفون و دوربین | ✅ | ✅ (حتی وقتی به برنامه دیگری می‌روید) |
| **اشتراک صفحه گوشی (Screen Share)** | ❌ | ✅ |
| نوار ابزار کامل پرزنتر | ❌ نسخه موبایل | ✅ «حالت دسکتاپ» |
| آپلود فایل، پی‌دی‌اف، وایت‌برد | ✅ | ✅ |

**دانلود:** [androidSkyRoom.apk](https://github.com/sadeghbashi73/androidSkyRoom/releases/latest/download/androidSkyRoom.apk)
(یا دکمه «دانلود اپ اندروید» در خود سایت).

### طرز کار

- کلاس داخل یک WebView باز می‌شود و صفحه‌های همین PWA داخل APK بسته‌بندی شده‌اند.
- اپ یک `getDisplayMedia()` واقعی به صفحه اسکای‌روم اضافه می‌کند
  (`android/app/src/main/assets/screenshare-shim.js`): وقتی دکمه اشتراک صفحه
  اسکای‌روم را می‌زنید، پنجره استاندارد اندروید (MediaProjection) اجازه می‌خواهد، و
  تصویر صفحه گوشی (حدود ۱۰ فریم در ثانیه، حداکثر ۱۲۸۰ پیکسل) به یک
  `MediaStreamTrack` تبدیل می‌شود که اسکای‌روم مثل اشتراک صفحه دسکتاپ ارسال می‌کند.
- مجوز میکروفون/دوربین صفحه به مجوز اندروید وصل است، و یک سرویس پیش‌زمینه
  (اعلان «کلاس اسکای‌روم باز است») صدا و اشتراک صفحه را هنگام رفتن به برنامه‌های
  دیگر زنده نگه می‌دارد.
- «حالت دسکتاپ» (پیش‌فرض روشن، از منوی ☰) اپ را به‌شکل کروم ویندوز معرفی می‌کند تا
  اسکای‌روم دکمه‌های پرزنتر از جمله اشتراک صفحه را نشان دهد.

### استفاده به‌عنوان پرزنتر

1. APK را نصب کنید (اجازه «نصب از منابع ناشناخته» را بدهید).
2. کلاس را اضافه کنید و «ورود به کلاس» را بزنید؛ وارد حساب اسکای‌روم شوید.
3. وقتی اندروید اجازه میکروفون خواست، **Allow** بزنید.
4. پس از گرفتن نقش ارائه‌دهنده، دکمه **اشتراک صفحه** اسکای‌روم را بزنید ←
   در پنجره اندروید **Start now / شروع** (در اندروید ۱۴+ «Entire screen») را انتخاب کنید.
5. حالا به پی‌دی‌اف، گالری یا هر برنامه‌ای بروید؛ همان برای کلاس پخش می‌شود.
   توقف: از اعلان «توقف اشتراک صفحه» یا دکمه توقف داخل اسکای‌روم.

> نکته: برای پایداری کلاس، در تنظیمات اندروید مصرف باتری این اپ را روی
> «بدون محدودیت / Unrestricted» بگذارید.

### ساخت APK

APK با GitHub Actions ساخته می‌شود (`.github/workflows/android.yml`) و با هر push
روی `main` در [Releases](https://github.com/sadeghbashi73/androidSkyRoom/releases)
منتشر می‌شود. امضای ریلیز از secrets مخزن خوانده می‌شود
(`ANDROID_KEYSTORE_B64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`).
ساخت محلی: `cd android && ./gradlew assembleDebug` (نیاز به JDK 17 و Android SDK).

## 🚀 شروع سریع

### ۱. نصب و اجرا (محلی)

```bash
cd skyroom-pwa
npm start
```

سپس مرورگر را باز کنید به:

```
http://localhost:5173
```

> ⚠️ **نکته مهم:** Service Worker روی `file://` کار نمی‌کند. حتماً باید از طریق یک وب‌سرور محلی اجرا شود.

### ۲. ساخت آیکون‌های PNG (یک‌بار)

برای اینکه PWA روی اندروید به‌درستی نصب شود، باید آیکون‌های PNG از روی SVG ساخته شوند.
اسکریپت زیر **بدون هیچ پکیج خارجی** کار می‌کند (فقط Node.js پیش‌فرض) و نیازی به
`npm install` یا اینترنت ندارد:

```bash
node tools/generate-icons.js
```

خروجی در پوشه `icons/` ساخته می‌شود. اگر می‌خواهید رنگ یا شکل آیکون را عوض کنید،
فایل `icons/icon.svg` را ویرایش کنید و دوباره همین دستور را اجرا کنید.

> روش مرورگری (`tools/generate-icons.html`) همچنان به‌عنوان گزینه جایگزین وجود دارد.

### ۳. نصب روی گوشی اندروید

برای اینکه Service Worker فعال شود، PWA **باید** روی HTTPS باشد. ساده‌ترین راه‌حل‌ها:

| روش | مزیت | هزینه |
|-----|------|------|
| **ngrok** | سریع، بدون ثبت‌نام | رایگان |
| **cloudflared** | سریع، CDN رایگان | رایگان |
| **GitHub Pages** | دائمی، رایگان | رایگان |
| **Netlify** | دائمی، با CI/CD | رایگان |
| **Vercel** | سریع، رایگان | رایگان |

#### تست سریع با ngrok:

```bash
# در یک ترمینال
npm start

# در ترمینال دیگر
ngrok http 5173
```

سپس لینک `https://xxxx.ngrok-free.app` را در کروم اندروید باز کنید و از منوی ⋮ گزینه **Add to Home screen** را بزنید.

#### دیپلوی دائمی روی GitHub Pages:

```bash
git init
git commit -am "init"
git branch -M main
git remote add origin https://github.com/YOUR_USER/skyroom-pwa.git
git push -u origin main
```

سپس در Settings → Pages → Branch: `main` → Save. بعد از چند دقیقه سایت شما در `https://YOUR_USER.github.io/skyroom-pwa/` در دسترس خواهد بود.

## 🎯 نحوه کار با اسکای‌روم

### سناریو ۱: استفاده به‌عنوان شرکت‌کننده (دانش‌آموز/دانشجو)

1. لینک کلاس را از معلم/استاد بگیرید (مثلاً `https://skyroom.online/chs/room/abc123`).
2. در PWA دکمه ➕ را بزنید.
3. نام کلاس + لینک را وارد کنید و ذخیره کنید.
4. روی کلاس مورد نظر بزنید تا صفحه آماده‌سازی باز شود.
5. دسترسی میکروفون/دوربین را فعال کنید.
6. دکمه **🎬 ورود به کلاس** را بزنید.

### سناریو ۲: استفاده به‌عنوان مدرس

1. کلاس‌های پرکاربرد را با اطلاعات ورود ذخیره کنید.
2. قبل از شروع کلاس، PWA را باز کنید.
3. **🔆 روشن نگه داشتن صفحه** را فعال کنید.
4. وارد کلاس شوید.

## 🛠️ رفع مشکلات

### PWA نصب نمی‌شود
- مطمئن شوید که سایت روی دامنه HTTPS باز می‌شود (localhost فقط برای dev).
- در کروم اندروید، DevTools → Application → Manifest را چک کنید.
- کش مرورگر را پاک کنید.

### Service Worker ثبت نمی‌شود
- فقط روی HTTPS یا localhost کار می‌کند.
- `console` را در DevTools چک کنید.

### میکروفون/دوربین کار نمی‌کند
مهم‌ترین نکته: مجوز باید **داخل صفحه اسکای‌روم** داده شود، نه داخل این اپ.
هر سایت در وب مجوز جداگانه می‌گیرد، پس دکمه «تست دستگاه» در این اپ فقط سلامت
میکروفون گوشی را بررسی می‌کند و مجوز کلاس را فعال نمی‌کند.

- وارد کلاس شوید و وقتی اسکای‌روم پرسید، **مجاز / Allow** را بزنید.
- اگر اشتباهی رد کردید: Chrome ← منوی ⋮ ← Settings ← Site settings ←
  Microphone / Camera ← Allow.
- در تنظیمات اندروید: Privacy ← Microphone ← دسترسی مرورگر را روشن کنید.
- اگر آیکون میکروفون اسکای‌روم خاموش است، از نوار ابزار پایین آن را روشن کنید.
- سایت باید روی **HTTPS** باشد (یا `localhost`).

### گوشی در طول کلاس خاموش می‌شود
قفل صفحه (Wake Lock) فقط تا وقتی این صفحه باز است کار می‌کند و با ورود به کلاس
آزاد می‌شود. برای کلاس واقعی: تنظیمات اندروید ← Battery ← مصرف مرورگر را روی
**بدون محدودیت / Unrestricted** بگذارید.

### آیکون نصب نمایش داده نمی‌شود
- با `node tools/generate-icons.js` فایل‌های PNG را دوباره بسازید.
- Manifest باید شامل حداقل یک PNG سایز 192x192 یا 512x512 باشد.
- فایل `icon.svg` نباید `purpose: maskable` داشته باشد، چون گوشه‌های شفاف دارد؛
  برای حالت maskable از `icon-maskable-512.png` استفاده کنید.
